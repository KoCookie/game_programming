## How This Evidence Supports Progress Over Time

The screenshots show a clear progression from a simple prototype to a more complete game. The early prototype and coloured-block evidence show the starting point. The menu, level selection, intro popup, and final gameplay screenshots show the game becoming a more complete player experience. The memory thief, gate blocker, and later-level screenshots show that the project expanded from a basic memory grid into a larger set of configurable mechanics.
