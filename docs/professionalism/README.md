# Professionalism Evidence

This folder contains supporting evidence for the Coursework 3 Professionalism Portfolio for **Afterimage**.

The files are organised around the portfolio requirements. They are written as a structured evidence pack so that the final submitted portfolio can refer to clear repository material rather than relying only on a final report.

| Portfolio requirement | Evidence file |
| --- | --- |
| GitHub repository link | Repository README and final portfolio |
| Development log showing progress over time | [PLANNING_AND_TASK_MANAGEMENT.md](PLANNING_AND_TASK_MANAGEMENT.md), [PROGRESS_EVIDENCE.md](PROGRESS_EVIDENCE.md) |
| Summary of important commits | [COMMIT_SUMMARY.md](COMMIT_SUMMARY.md) |
| Evidence of planning and task management | [PLANNING_AND_TASK_MANAGEMENT.md](PLANNING_AND_TASK_MANAGEMENT.md) |
| Evidence of response to feedback | [FEEDBACK_RESPONSE_LOG.md](FEEDBACK_RESPONSE_LOG.md) |
| Testing log and bug-fixing evidence | [TESTING_AND_BUG_FIX_LOG.md](TESTING_AND_BUG_FIX_LOG.md) |
| Screenshots or short evidence of progress over time | [PROGRESS_EVIDENCE.md](PROGRESS_EVIDENCE.md), [screenshots/](screenshots/) |
| Explanation of how the project changed during development | [PROJECT_EVOLUTION.md](PROJECT_EVOLUTION.md) |
| External assets, templates, tutorials, or AI declaration | [AI_AND_EXTERNAL_RESOURCES_DECLARATION.md](AI_AND_EXTERNAL_RESOURCES_DECLARATION.md) |
| Credits and licences | [AI_AND_EXTERNAL_RESOURCES_DECLARATION.md](AI_AND_EXTERNAL_RESOURCES_DECLARATION.md), [../../THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md), [../licenses/](../licenses/) |
| Reflection on organisation, time management, independent work, and professionalism | [ORGANISATION_AND_PROFESSIONALISM_REFLECTION.md](ORGANISATION_AND_PROFESSIONALISM_REFLECTION.md) |
| Known limitations and how they were managed | [LIMITATIONS_AND_RISK_MANAGEMENT.md](LIMITATIONS_AND_RISK_MANAGEMENT.md) |

The material here is retrospective but evidence-based. It is aligned with the repository commit history, the current Unity project, the submitted game build, the external asset notices, and the development decisions made during the project.
