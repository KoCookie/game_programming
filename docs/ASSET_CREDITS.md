# Asset Credits

This project uses imported third-party assets for visual and UI styling. Asset licenses should be checked before public release or redistribution.

## Kenney Assets

Imported Kenney assets are stored under `Assets/Art/Kenney/`.

Used packs include:

- Abstract Platformer
- Puzzle Pack 2
- UI Pack
- UI Pack Sci-Fi
- UI Audio

Kenney assets are commonly released under Creative Commons CC0, but each downloaded pack should be verified from its original Kenney page before final publication.

## Unity Packages

- TextMesh Pro: included through Unity package dependencies.
- Unity 2D packages: included through the Unity package manifest.

## Other Assets

The project also contains a `JazzCreate` asset folder. If any assets from this folder are used in the final game, keep its original documentation and license terms with the project.

## Attribution Notes

Even when attribution is not required by a license, keeping this document updated makes the repository easier to review and helps future contributors understand where assets came from.
